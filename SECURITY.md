# Security Policy

## Scope

This project is a local-only test harness for authorized SMS workflow testing. It does not send real messages, integrate with SMS providers, discover targets, or provide bulk messaging capabilities.

## Reporting a vulnerability

If you find a security issue in the harness or its documentation, please open a private security advisory through GitHub when available. Do not include phone numbers, API keys, personal data, or other sensitive information in a public issue.

For ordinary bugs and improvements, open a focused issue or pull request with reproduction steps, expected behavior, and the smallest useful test case.

## Safe disclosure

Please allow time for a fix before public disclosure. Never test this project against systems, phone numbers, or provider accounts you do not own or have explicit permission to assess.
